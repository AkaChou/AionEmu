# 国际化、注释与术语规则

## 中英双语注释

1. 新增或修改的代码注释必须同时包含中文和英文，并在同一注释块中表达一致含义；禁止只翻译标识符或添加没有设计信息的空泛注释。
2. 新增或修改的类、接口、枚举和 record 必须有中英双语类级 Javadoc，说明职责、边界以及必要的生命周期或线程安全约束。
3. 重要方法必须有中英双语方法级 Javadoc。重要方法包括公共 API、核心业务流程、状态迁移、协议处理、事务或并发边界、生命周期入口，以及具有非显然副作用或失败语义的方法；注释应按需说明参数、返回值、副作用、异常和关键前置条件。
4. 简单 getter/setter、语义显然的委托和无需补充合同的短小 override 不强制添加方法注释；一旦添加或修改注释，仍必须使用中英双语。

## 日志国际化

1. 所有新增或修改的日志调用必须通过 `I18n.get(...)` 获取文本，不得直接写字符串或使用 `String.format(...)` 拼接可见日志。
2. 消息 key 必须同时加入 `src/main/resources/messages.properties` 和 `src/main/resources/messages_zh_CN.properties`，参数占位符及语义保持一致。
3. 修改日志后将 `LocalizedLogCallsTest` 和两个语言包的 key 对齐作为必要验收项。

## 术语

1. 中文和英文名词、玩家可见文案、注释及日志用词统一参考 `docs/aion-game-terms-en-zh.md`。
2. 词典已有条目时使用其规范译名，不自行创造同义译法。
