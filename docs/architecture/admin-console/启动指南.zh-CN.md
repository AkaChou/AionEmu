# AionEmu 管理控制台启动指南

> 版本：2026-10-26 · 适用范围：`config/administration/` 第一批
> Version: 2026-10-26 · Scope: the first `config/administration/` batch

控制台与游戏服**同进程**运行：嵌入式 Tomcat 随游戏服启动，页面由同一个 JAR 提供。
因此「启动 web」就是「启动游戏服」，没有独立的控制台进程。

The console runs **in the same process** as the game server: the embedded Tomcat starts with the game server and
serves the page from the same JAR. So "starting the web" means "starting the game server"; there is no separate
console process.

---

## 一、三种启动方式 (Three Ways to Start)

### 1. 开发模式（前后端分离，改前端即时生效）— 推荐日常开发

```bash
# 终端 1：启动游戏服（内嵌 Tomcat 提供 API）
./scripts/start-silent.sh          # 或在 IDEA 里直接运行 AionBootApplication

# 终端 2：启动 Vite 开发服务器
cd web && pnpm install && pnpm dev
```

打开 **http://127.0.0.1:5173** 。Vite 把 `/api` 代理到 `127.0.0.1:8080`（见 `web/vite.config.ts`），
前端热更新即时生效，无需重新构建前端产物。

Open **http://127.0.0.1:5173**. Vite proxies `/api` to `127.0.0.1:8080` (see `web/vite.config.ts`), so frontend
hot reload works without rebuilding the frontend assets.

> 控制台界面默认**中文**，右上角可即时切换英文。界面文案走前端字典（`web/src/i18n/dictionaries.ts`）；
> 配置键的备注直接取自配置文件里的双语注释块，两侧语言始终与文件内容一致。
>
> The console UI is **Chinese by default**; the switch in the top right changes to English instantly. The UI
> copy lives in a frontend dictionary (`web/src/i18n/dictionaries.ts`), while the descriptions of the
> configuration keys come straight from the bilingual comment blocks in the configuration files, so both
> languages always match the file content.

### 2. IDE 运行（IDEA 里跑游戏服 + 访问内嵌 Tomcat）

在 IDEA 中直接运行 `com.aionemu.AionBootApplication`。此时：

- classpath 指向 `target/classes`，`web/dist` 经 `<resources>` 映射到 `target/classes/static`；
- 若增量构建尚未拷贝前端产物，`AdminConsoleStaticAssetsEnvironmentPostProcessor` 会把磁盘上的 `web/dist`
  加入静态资源位置，页面不会 404；
- 打开 **http://127.0.0.1:8080** 即可。

Run `com.aionemu.AionBootApplication` from the IDE. The classpath points at `target/classes`, and `web/dist` is
mapped into `target/classes/static` by the `<resources>` declaration. When an incremental build has not copied
the frontend assets yet, `AdminConsoleStaticAssetsEnvironmentPostProcessor` adds the on-disk `web/dist` to the
static resource locations so the page does not 404. Open **http://127.0.0.1:8080**.

### 3. 打包部署（生产形态）

```bash
./scripts/package.sh        # 先 pnpm install && pnpm build，再 mvn package，最后同步到 aion/
./aion/start-silent.sh      # 启动，日志在 aion/log/aionemu.log
```

打开 **http://127.0.0.1:8080** 。

```bash
./scripts/package.sh        # runs pnpm install && pnpm build first, then mvn package, then syncs into aion/
./aion/start-silent.sh      # starts it; the log is at aion/log/aionemu.log
```

Open **http://127.0.0.1:8080**.

## 二、登录 (Sign In)

默认账号与密码均为 **`aion`**，见 `config/web/web.properties`：

| 键 / Key | 默认值 / Default | 说明 / Description |
|---|---|---|
| `web.enabled` | `true` | 关闭时完全不启动 Web 层 / When false the web layer does not start at all |
| `web.address` | `127.0.0.1` | 只绑定回环地址 / Binds the loopback address only |
| `web.port` | `8080` | 监听端口 / Bind port |
| `web.username` | `aion` | 登录用户名 / Login user name |
| `web.password` | `aion` | 登录密码 / Login password |
| `web.session.timeout` | `120` | 会话有效期（分钟）/ Session lifetime in minutes |

> **对外暴露前必须改掉 `web.password`。** 控制台可以修改 GM 权限等级与命令权限，默认凭据等同于开放权限体系。
>
> **Change `web.password` before exposing the console.** The console can change GM access levels and command
> permissions, so the default credentials amount to an open permission system.

## 三、菜单结构 (Menu Structure)

菜单是**两级**的：一级是配置分组，二级是该分组下的配置文件。

The menu has **two levels**: the configuration groups at the top and the configuration files of a group below.

| 一级菜单 / Group | 覆盖范围 / Coverage |
|---|---|
| 管理配置 / Administration | `administration/` 下的六个文件 / the six files under `administration/` |
| 主服配置 / Main | `main/` 目录下全部 44 个 `.properties` / every `.properties` under `main/` |
| 商城管理 / Shop | 商城开关与商城限制（与「主服配置」共享）/ the shop switches and limits, shared with "Main" |

商城管理目前是**骨架**：分组与路由已就位，商品定义（`ingameshop/in_game_shop.xml`）的编辑能力在下一批接入。

Shop management is a **skeleton** for now: the group and the routing are in place, and the editing of the item
definitions (`ingameshop/in_game_shop.xml`) lands in the next batch.

## 四、配置位置 (Where the Configuration Lives)

| 场景 / Scenario | 配置文件 / Configuration file |
|---|---|
| IDE 运行 / IDE run | `src/main/resources/aion/config/web/web.properties` |
| 打包部署 / Packaged run | `<aion.home>/config/web/web.properties`（即 `aion/config/web/web.properties`） |

判定规则与其它运行时配置一致：未设置 `aion.home` 时用源码树，否则用 `<aion.home>/config`。

The rule matches the other runtime configuration: the source tree is used when `aion.home` is not set, otherwise
`<aion.home>/config` is used.

**改了 `web.enabled` / `web.port` / `web.address` 需要重启才生效** —— 它们决定的是 Web 层是否启动与监听哪里。

**Changes to `web.enabled` / `web.port` / `web.address` need a restart** — they decide whether the web layer starts
and where it listens.

## 五、排查 (Troubleshooting)

### 页面 404 或白屏

1. 前端产物是否构建过：`ls web/dist/index.html`。没有则 `cd web && pnpm build`。
2. IDE 运行时确认 `target/classes/static/index.html` 存在；不存在则执行一次 Maven 构建
   （IDEA 的 Maven 面板 → `Lifecycle` → `process-resources`）以触发 `<resources>` 拷贝。

### 8080 端口没有监听

控制台没有起来。最常见的原因是 `application.yml` 里出现了 `spring.main.web-application-type`：该键会在环境
绑定阶段覆盖 `SpringApplicationBuilder.web(...)` 的取值，使 Tomcat 永不启动。该键**不应存在**。

The console did not start. The usual cause is a `spring.main.web-application-type` key in `application.yml`: it is
rebound during the environment binding stage, overrides the `SpringApplicationBuilder.web(...)` value and keeps
Tomcat from ever starting. The key **must not** be there.

### 启动日志里找不到控制台信息

控制台状态在 `ApplicationReadyEvent` 之后打印（`AdminConsoleStartupLogger`）。日志级别调高到 `INFO` 即可看到
`console.web.config_loaded`。

The console state is logged after `ApplicationReadyEvent` (`AdminConsoleStartupLogger`). Raise the log level to
`INFO` to see `console.web.config_loaded`.
