# 真端 npc 模板对齐：实机验收清单

> 适用提交：`feat(static-data): align npc templates with retail npcs.xml`
> 改动面：`npc-combat.xml` +46,070 行；8 个 `npc_template_*.xml` 分片共 19,218 条攻击档位写回。
> 所有样本值均与真端 `58Server/Map/XML/npcs.xml` 逐字段核对过（列内「真端值」）。

## 前置

1. 用**改动后**的静态数据启动服务端（`target/AionEmu.jar` 需重新打包，或 IDE 直接跑 `target/classes`）。
2. 准备一个管理员账号，用刷怪命令按 id 生成样本 NPC：`//spawn <npc_id>`（按你的 GM 配置命令为准）。
3. 打开战斗日志/伤害飘字，便于观察单次伤害。

## 五、失败处置

| 现象 | 处置 |
|---|---|
| 伤害整体异常 | 回滚 `npc-combat.xml` 到上一提交（单文件即可） |
| 攻击距离/攻速异常 | 回滚对应的 `npc_template_*.xml` 分片 |
| 单个 NPC 异常 | 在对应分片里单独修该 id 的三个属性，重新跑 `NpcTemplateRetailAlignmentTest` |
