# 塔奇的冒险露娜副本书（301630000 / 301640000）

## 基本信息

- 副本：污染暗道（Contaminated Underpath，`301630000`）、秘密军工厂（Secret Munitions Factory，`301640000`）
- 入口：露娜商店「塔奇的冒险」页签，`CM_LUNA_SHOP` action 0 → `LunaShopService.takiAdventureTeleport`（每次 20 露娜，`isFreeUnderpath/isFreeFactory` 免费 flag 除外）
- 对齐目标：Aion 5.8 原版 `IDLuna_def` / `IDLuna_siege` 世界数据（条件刷怪、阶段链、巡逻路径、门、结算）。
- 当前状态：刷怪**完全交给原版数据**——`condition-spawns.xml` + `RetailPatternAI2` 承担全部怪物生成与阶段推进；实例处理器只保留计时、计分、门、掉落、效果与结算，不含任何手写刷怪兜底。

- `58Server/Map/Worlds/IDLuna_siege/world_N.xml` → `301640000` 块：**153 条条件**，全部投影。
- 路径：`IDLuna_siege/world_N_WayPoint_1.xml` 的 `NPCPath1st_Monster_Path6/9/14` 投影为 `retail:301640000:npcpath1st_monster_path6|9|14`。

原版重生语义（`no_respawn="FALSE"` 的 territory，共 36 条条件、82 个 NPC）：

- `<spawn_time>` / `<spawn_time_ex>` 投影为 `respawn_delay` / `respawn_delay_extra`（秒）；首次生成仍用 `<initial_spawn_time>`。

## 启动链

两个副本的阶段链由同一个钩子启动：实例处理器 `startMainInstanceTimer()`（开门或准备计时结束的唯一入口）调用
`RetailConditionSpawnEngine.setVariable(instance, "TIMEATTACK_PLAY_START", 1, 0)`。

- 污染暗道：`TIMEATTACK_PLAY_START==1` 刷出阶段触发器 `IDLUNA_DEF_PHASE_1_1..1_7`、`BarPhase_01/02` 与火龙/警报 NPC；波次怪 `on_die` 累加 `IDLUNA_DEF_PHASE_1/2/3`；阈值 `>=300/450` 刷出 `Phasenpc_*` 推进阶段；`IDLUNA_DEF_PHASE_4` 为 MAAD-S 首领波 + ClodWorm；`IDLUNA_DEF_END` 收尾。路障链 `idluna_def_barricade_01..03`。
- 秘密军工厂：`TIMEATTACK_PLAY_START==1` 刷出联盟小队（`833826/833827/833828/833829/833897`）与首波怪；`IDLUNA_SIEGE_S2_Tesinon`（首领）按 HP 70%/30% 写 `Rolling_Golem_01/02` 触发魔像链；`LEFT_BOMB_SPAWN`、`Enemy_Cannon`、`2STAGE_OPEN`、`EXP_SPAWN_01`、`QUEST_SPAWN_01..07`、`Reward_Treasure_02`、`ALLSTAGE_END` 全部由条件与 AI pattern 驱动。

## AI 操作码审计

`RetailLunaPatternSupportTest`（`src/test/java/com/aionemu/gameserver/ai/`）作为回归闸门：

- 两世界条件数 == 原版（229/153），关键表达式存在（`TIMEATTACK_PLAY_START==1`、`IDLUNA_DEF_END==1`、`Rolling_Golem_01==1`、`2STAGE_OPEN==1`、`ALLSTAGE_END==1`）。
- AI 写入的全部变量均已声明（`supportsConditionVariable`）。
- 条件刷怪 NPC 均能解析到 NPC AI 映射与 pattern。
- 两世界全部 pattern（`idluna_def*`/`idluna_siege*`）通过 `RetailPatternAI2.supports(pattern)`。

静态审计结论（交付时核验）：两文件用到的 13 种事件、全部条件/动作操作码与参数、事件上下文（`OBJI_SEEN`/`OBJI_MESSAGE_SENDER`/`USERI_TALKER` 等）以及全部 `STR_*` 消息 id 均在支持范围与 `ai-strings.xml` 内，**无需新增操作码实现**。

## 风险与注意事项

- 无实例层兜底：若原版链某环节未触发（例如触发器 NPC 被 geo 卡住），副本会停在对应阶段；排障入口是 `RetailLunaPatternSupportTest` 与服务端日志中 `RetailConditionSpawnEngine`/`RetailPatternAI2` 的输出。
- 新增无条件 NPC 的 z 值依赖本地 geo，如发现悬空/入地按实测面高微调。
- 原版字符串 id 与数字消息的映射在 `ai-strings.xml`（如 `STR_MSG_IDLUNA_SIEGE_Reward_obj_02`=1403641）；本地自定义消息（1403647/1403648/1403653）无原版对应，已随旧逻辑删除。
