# 任务目录与任务名称 ID 全量对齐排查修复报告

## 背景
用户在核对任务目录（`docs/QUEST_CATALOG.zh-CN.md`）时发现：
1. 任务 `10034` 奖励为盾牌，法系职业无法佩戴。经核查官方 5.8 客户端 `quest.xml` 与道具库，证实该任务可选奖励官方原版即为两面 54 级唯一盾牌（物理/魔抗），全游戏无同阶法系武器替代，属于官方原版设计。
2. 任务 `10035`（Soar to the Corridor）中文名称被错误标记为《地下神殿的秘密空间》（与 10034 相同）。

## 根因分析
在任务静态数据 `quest_definition/quests/10035.xml` 和 `quest_data/quest_data.xml` 中，`display-name-id` / `nameId` 被误填为前一个任务的 `1141845`，而官方 5.8 客户端正确 ID 为 `1141846`（`STR_QUEST_NAME_Q10035`，中文名《锡兰泰拉回廊进军准备》）。

通过对比官方 5.8 客户端（`/Users/mc/PycharmProjects/unpak/`），对服务端全量 6,222 个任务进行了全要素扫描，发现类似错误多达 219 处，主要分类为：
- **错位映射至其他任务名称（116 处）**：如 10035 错映射至 10034、10100 错映射至 10101、80721~80736 等活动任务整体偏移。
- **错位映射至物品说明或非任务文本（41 处）**：如 4115 映射为道具说明文本。
- **引用客户端不存在的非法 ID（33 处）**：如 18219~18223（竞技场任务）填为 `2259269`，导致目录显示为“未找到客户端名称”。
- **别名/老版本 ID 冗余（23 处）**。

此外，任务目录（`docs/QUEST_CATALOG.zh-CN.md`）还存在：
- 47 处前置任务列由于历史 XML 修复后未同步导致的漂移（如 1466、1877~1885 等）。
- 5 处英文名称轻微拼写/大小写漂移。

## 修复范围
1. **任务定义修正**：
   - 修复 `src/main/resources/aion/data/static_data/quest_definition/quests/*.xml` 共 213 个文件中的 `display-name-id`。
   - 同步更新 `src/main/resources/aion/data/static_data/quest_data/quest_data.xml` 中对应的 210 处 `nameId`。
2. **任务目录文档更新（`docs/QUEST_CATALOG.zh-CN.md`）**：
   - 刷新生成日期为 `2026-09-18`。
   - 修正 199 处中文任务名称（包括 10035 正名为《锡兰泰拉回廊进军准备》、18219~18223 恢复为《挑战荣耀竞技场1~5》等）。
   - 同步 47 处前置任务列。
   - 对齐 5 处英文名称列。
3. **验证结果**：
   - 6,222 个任务 XML 全部通过语法解析。
   - `quest_data.xml` 语法解析有效。
   - `docs/QUEST_CATALOG.zh-CN.md` 全量 6,222 行格式与列数 100% 合规。
