# 任务 10525 s4/s5 报告链 dialog 31 与交付后续按钮缺失（questId=0 下发页=10）

- 日期：2026-09-21
- 范围：`10525`（天族）/ `20525`（魔族镜像）
- 状态：**实现完成、XML/XSD/IDE 静态验证与 Maven 聚焦测试通过；客户端实机复测未做（PENDING_CLIENT）**
- 关联前序证据：`.agents/summary/quest-10525-testimony-counter/2026-09-21-10525-testimony-counter-overflow.zh-CN.md`

## 一、现象

2026-09-21 13:37:04 玩家 `Ww` 在 NPC `806134`（Aldor / 圣所管理者）处反复点击任务行：

```text
[QUEST-TRACE][C->S] CM_DIALOG_SELECT 玩家=Ww npcId=806134 targetObj=13932 questId=10525 上一页=10 动作=31
[QUEST-TRACE][S->C] SM_DIALOG_WINDOW 玩家=Ww targetObj=13932 questId=0 下发页=10
```

用户描述为“和 npc806134 汇报，对话无法进行”。`动作=31` 是 `QUEST_SELECT`；服务端回 `questId=0` 的第 10 页，
说明该状态下没有匹配的任务路由，走了通用任务列表兜底。

## 二、根因

### 1. s4 报告入口缺 `QUEST_SELECT(31)` 路由

客户端对话映射（`docs/quest/client-dialog-mapping/quest-dialog-action-details.csv:784-785`）显示：

- `select5` 页 `2375` 的按钮是 `HACTION_CHECK_USER_HAS_QUEST_ITEM(39)`，文案“交出光之魔力石”；
- 只有先下发 `2375`，玩家才能提交三种收集材料。

旧 handler `_10525Agent_Viola_Call` 在 `var == 4` 的 `START_DIALOG` 分支明确 `sendQuestDialog(env, 2375)`。
但 `10525.xml` 的 `s4` 只有 `CHECK_USER_HAS_QUEST_ITEM`、`SELECT6`、`FINISH_DIALOG` 等路由，缺少
`TALK_TO_NPC(806134, QUEST_SELECT) -> SHOW_QUEST_PAGE SELECT5(2375)`。因此客户端点任务行发 31 时无路由，
服务端只回 `questId=0/page=10`。魔族镜像 `20525.xml` 已有该路由。

### 2. s5 交付成功后续按钮缺 `SELECT6(2716)` 路由

材料提交成功后，`s4 -> s5` 的 after-commit 下发 `CHECK_USER_ITEM_OK(10000)`。客户端该页按钮是
`HACTION_SELECT6(2716)`（映射表 `quest-dialog-action-details.csv:785-788`）：

```text
check_user_item_ok(10000) -> SELECT6(2716) -> select6(2716)
select6(2716)             -> SELECT6_1(2717) -> select6_1(2717)
select6_1(2717)           -> SETPRO6(10005) -> 结束对话
```

`20525.xml` 的 `s5` 有 `SELECT6 -> SHOW_QUEST_PAGE SELECT6(2716)`，`10525.xml` 漏了这条边；
即使补齐 s4 入口，玩家在 10000 页继续点击仍会再次落到通用第 10 页。

## 三、修复

### 1. `quests/10525.xml`

- `s4` 新增：

```xml
<transition source="s4" target="s4">
  <event><dialog type="TALK_TO_NPC" npc-id="806134" action="QUEST_SELECT"/></event>
  <conditions><variable-is field="var0" value="4"/></conditions>
  <after-commit><dialog type="SHOW_QUEST_PAGE" page="SELECT5"/></after-commit>
</transition>
```

- `s5` 新增：

```xml
<transition source="s5" target="s5">
  <event><dialog type="TALK_TO_NPC" npc-id="806134" action="SELECT6"/></event>
  <after-commit><dialog type="SHOW_QUEST_PAGE" page="SELECT6"/></after-commit>
</transition>
```

两条边都在文件内补了中英双语说明。`20525.xml` 已有等价路由，本轮不改生产内容，只纳入回归测试守护。

### 2. `QuestDialog31RegressionTest`

新增 `migratedQuestHandlersKeepLegacyTurnInDialogRoutes`，同时锁定：

- `10525.xml` / `20525.xml`：`s4 + NPC + QUEST_SELECT(31) -> page 2375`，条件 `var0=4`；
- `10525.xml` / `20525.xml`：`s5 + NPC + SELECT6(2716) -> page 2716`。

并把测试辅助方法从只支持 action 31 泛化为 `assertDialogAction(..., action, page, ...)`，
现有 31 路由断言保持不变。
