# QuestDialog phase-1 internal migration / QuestDialog 第一阶段内部迁移

## Scope / 范围

- Migrate production Java call sites from the legacy mixed `questEngine.model.QuestDialog` enum to:
  - `QuestDialogAction` for client HyperLinks actions.
  - `QuestDialogPage` for client HtmlPages pages.
- Remove the unused `QuestEnv.getDialog()` / `QuestEngine.getDialog(int)` compatibility lookup and its startup map.
- Convert the last explicit numeric production quest-dialog routes in `25306.xml` and `25321.xml` to typed action/page symbols.
- Add typed `QuestDialogPage` overloads for `QuestDsl.showQuestDialog` and `QuestDsl.showQuestSelectionDialog`.
- Migrate 55 wildcard `<talk-to-npc npc-id="..."/>` routes across 45 production quest files to typed
  `<dialog type="TALK_TO_NPC" npc-id="..."/>` routes; omitting `action` preserves the null dialog-id wildcard.
- Keep `<show-dialog-window dialog-id="..."/>` because it sends a generic window without a quest id; it is not semantically interchangeable with `SHOW_QUEST_PAGE`.
- Add `QuestDialogMigrationGateTest` to prevent production Java/XML from reintroducing the migrated legacy forms.
- Repair `generate_quest_dialog_enums.py` so its output retains the cached id lookup, reward-window helper,
  reward-owner action helper, and the two manually required lifecycle pages.

## Static evidence / 静态证据

- No production or test Java source references `questEngine.model.QuestDialog` or a legacy `QuestDialog.*` constant outside the compatibility enum itself (the new gate test necessarily contains the forbidden string in its scanner).
- Production quest XML has no `<talk-to-npc>`, `<quest-dialog>`, `<show-quest-dialog>`, or `<show-quest-selection-dialog>`.
- `xmllint --noout` passed for `25306.xml` and `25321.xml`.
- `xmllint --noout` passed for all 47 quest XML files touched by this migration.
- IDE error-level inspection passed for all touched Java files.
- `git diff --check` passed.
- `python3 -m py_compile .agents/summary/quest/generate_quest_dialog_enums.py` passed.
- `python3 .agents/summary/quest/generate_quest_dialog_enums.py` regenerated both enums without changing their committed content.
- `python3 .agents/summary/quest/generate_quest_dialog_enums.py --check` passed with `actions=195 pages=156`.
