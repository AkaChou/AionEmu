# QuestDialog phase-2 removal / QuestDialog 第二阶段彻底删除

## Scope / 范围

- Delete `src/main/java/com/aionemu/gameserver/questEngine/model/QuestDialog.java`.
- Remove the legacy event and after-commit XML parser branches for:
  - `<talk-to-npc>`
  - `<quest-dialog>`
  - `<show-quest-dialog>`
  - `<show-quest-selection-dialog>`
- Remove the corresponding XSD declarations, numeric `dialog-id` / `dialog-ids` compatibility attributes, and the shared numeric dialog-id list parser.
- Convert remaining compiler-facing domain-block compatibility syntax to typed symbols:
  - `npc-start.start-dialog-id` -> `npc-start.start-page`
  - numeric `npc-report.page` -> `QuestDialogPage` symbol
  - `npc-complete.dialog-ids`, `preview-dialog-ids`, `choice.dialog-id`, and `fallback.dialog-ids`
    -> `actions` / nested `<preview actions="...">`
  - `npc-dialog.dialog-ids` -> `npc-dialog.action` or `npc-dialog.actions`
- Keep `<show-dialog-window dialog-id="..."/>`: it is a generic non-quest window with its own client ID space, not `SHOW_QUEST_PAGE`.
- Update the enum generator, production schema, test fixtures, focused tests, and both writing guides so they no longer teach or accept the removed syntax.
- Extend `QuestDialogMigrationGateTest` to keep the old enum deleted and prevent production definitions or the generator from reintroducing legacy tags/attributes.
