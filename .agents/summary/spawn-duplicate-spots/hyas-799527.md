# Hyas 799527 重复刷出 / Duplicate Hyas spawn (300190000)

## 症状 / Symptom

- 真端反馈：Taloc's Hollow（map 300190000）同一个实例内出现 2 个 `Hyas`（npc 799527）。
- Client target dump: `Hyas` at x=203.16, y=819.34, z=1214.36, `ai=retail_pattern`.

## 加载归属 / Spawn ownership

- 静态残留：`src/main/resources/aion/data/static_data/spawns/Instances/300190000_Taloc's_Hollow.xml`
  曾无条件生成 `<spawn npc_id="799527">`，坐标为 203.517 / 819.265 / 1214.4。
- 真端归属：`src/main/resources/aion/definitions/compact/ai/npcaipatterns_idelim_osy.xml`
  的 `Elim_ClodwormNm.on_die`（由 npc 215467 使用）会：
  1. 在绝对坐标 203 / 819 / 1214、range=1 生成 `Hyas`；
  2. 设置 `IDElim_1F_NoshowNPC = 1`。
- 180 秒后 `condition-spawns.xml` 的 condition 3086 生成 npc 282109
  (`BIDElim_NPCKill_NoshowNPC`, AI `Elim_Broad1`)，它广播 message 6763。
  `Elim_HealPlant2` 收到 6763 后会让 Hyas 说退场台词并 `despawn_self`。
- 结论：真端 Hyas 是 1F Boss 死亡后限时出现的条件 NPC，不是进入副本即存在的静态 NPC；
  静态 spawn 属于旧实现残留，必须删除。

## 处置 / Change

- 从 `300190000_Taloc's_Hollow.xml` 删除静态 `<spawn npc_id="799527">` 块。
- Retail pattern 保留为 799527 的唯一加载来源。

## 验证边界 / Validation boundary

- Static: XML well-formed check passed.
- 未执行 Maven、服务端或真端客户端复验；本次结论基于客户端截图、静态 spawn 与 retail pattern 的交叉证据。
